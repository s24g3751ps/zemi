# ✏️ 文房具ECサイト 簡単インストールマニュアル

## 1. このアプリについて
文房具を購入できる、とてもシンプルなネットショップ（ECサイト）のアプリです。  
Python 3 の標準機能（`http.server` と `sqlite3`）だけで動くため、追加のパッケージを入れる必要がありません。  
プログラムは `server.py` という1つのファイルだけで作られています。

## 2. 必要なもの
- **Windows パソコン**（PowerShell を使います。管理者権限ではない普通の起動で大丈夫です）
- **wslc**（コンテナという「仮想の小さなパソコン環境」を動かすツールです。コマンドの wslc を podman や docker に置き換えれば、同じようにできます）

---

## 3. インストール手順
上から順にコマンドをコピーして実行してください。

### 手順1: コンテナの作成と起動
Windows の PowerShell を開き、以下のコマンドを実行します。  
（80番ポートというWeb通信の標準番号をつなぎ、Ubuntu というLinux環境を立ち上げます）

```powershell
wslc run -it -p 80:80 --name zemi-ec ubuntu.azurecr.io/ubuntu
```

※ 画面が `root@...:/#` のように変われば、コンテナの中に入れています。

### 手順2: コンテナの中でのセットアップと起動
コンテナの中で、以下のコマンドを1行ずつコピーして実行します。

```bash
apt update
DEBIAN_FRONTEND=noninteractive apt install -y python3 git
git clone https://github.com/s24g3751ps/zemi.git /var/www/zemi
cd /var/www/zemi
python3 server.py
```

> **💡 メモ：`DEBIAN_FRONTEND=noninteractive` について**  
> インストールの途中で「お住まいの地域はどこですか？」といった質問の画面が出て処理が止まってしまうのを防ぎ、自動で最後まで進めるためのおまじないです。

> **⚠️ 注意：必ず `cd /var/www/zemi` をしてから起動してください**  
> `server.py` は、今自分が作業しているフォルダの中に `shop.db`（データベース）を作ります。そのため、必ず `cd` でフォルダを移動してから `python3 server.py` を実行してください。

### 手順3: ブラウザで開く
ブラウザ（Chrome や Edge など）を開き、アドレスバーに以下を入力して開きます。

👉 **http://localhost**

文房具店の画面が表示されれば成功です！

---

## 4. 80番ポートが使われているとき
もし手順1を実行したときに「ポートがすでに使われている」というエラーが出た場合は、パソコンの別のアプリが80番を使っています。  
失敗したときに `zemi-ec` という名前のコンテナが残っていることがあるので、先に削除してからポート番号を `8080:80` に変えて作り直します。

```powershell
wslc rm zemi-ec
wslc run -it -p 8080:80 --name zemi-ec ubuntu.azurecr.io/ubuntu
```

この場合のブラウザのアドレスは以下のようになります。

👉 **http://localhost:8080**

---

## 5. 止め方と再開のしかた

### アプリの止め方
1. サーバーが動いている画面で **`Ctrl + C`**（Ctrlキーを押しながらC）を押すと、サーバーが停止します。
2. **`exit`** と入力してEnterを押すと、コンテナから抜けて元のWindows（PowerShell）に戻ります。

### 次回からの再開のしかた
すでにインストールは終わっているため、ダウンロードなどをやり直す必要はありません。PowerShellで以下の2行を実行してコンテナを再開します。

```powershell
wslc start zemi-ec
wslc exec -it zemi-ec bash
```

コンテナの中に入ったら、移動して起動します：

```bash
cd /var/www/zemi
python3 server.py
```

起動したら、ブラウザで **http://localhost**（または http://localhost:8080）を開きます。

## 6. データを最初の状態に戻す方法
お買い物をして減った商品の在庫や、注文履歴を初期状態にリセットしたいときは、データベースファイルを消すだけで簡単に戻せます。

1. **`Ctrl + C`** でサーバーを止めます。
2. 以下のコマンドでデータベースファイルを削除します：
   ```bash
   rm shop.db
   ```
3. 再びサーバーを起動します：
   ```bash
   python3 server.py
   ```
   ※ `shop.db` がない状態で起動すると、最初の5つの商品（えんぴつ・ノートなど）が自動で作り直されます。

---

## 7. 使い方
1. **カートに入れる**：欲しい商品の「カートに入れる」ボタンを押すと、画面中央のカート表に追加されます（在庫以上の数は入れられません）。
2. **注文する**：お名前を入力して「注文する」ボタンを押すと、注文が確定して在庫が減ります。
3. **注文履歴を見る**：画面下の「注文履歴」に、注文番号・お名前・購入した商品・合計金額が表示されます。

## 8. ファイルの説明

| ファイル名 | 役割 |
| :--- | :--- |
| **`server.py`** | Webサーバーの動き、画面（HTML/CSS）の作成、データベースの読み書きをすべて行っているメインのプログラムです（約150行）。 |
| **`shop.db`** | 商品の在庫、カートの中身、注文履歴が保存されるSQLiteのデータベースファイルです。最初の起動時に自動で作られます（Gitのリポジトリには含めません）。 |
| **`images/`** | えんぴつやノートなど、商品の写真画像が保存されているフォルダです。商品画像は Antigravity の画像生成機能で作りました。 |
